Вебзастосунок на Django, інтернет-магазину. В якому реалізований інструмент для автоматизації наповнення та оновлення каталогу. 

Основні можливості
Автоматичне оновлення прайсів: Система для парсингу та імпорту прайс-листів постачальників, що дозволяє тримати актуальні ціни та наявність товарів.

Каталог товарів: Повністю функціональна вітрина з категоріями та сторінками продуктів.

Проєкт повністю контейнеризований і готовий до швидкого розгортання на VPS.

🛠 Технологічний стек
Backend: Python 3, Django, BeautifulSoup, Requests.

Database: SQLite.

DevOps: Docker, Docker Compose.

Розгортання (Docker)
Застосунок підготовлений до роботи в ізольованому середовищі. Використання Docker Compose дозволяє розгорнути проєкт однією командою.
Dockerfile для інтернет-магазину та телеграм бота.
docker-compose.yml — опис сервісів для роботи на VPS.
